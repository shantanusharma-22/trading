description: Use for UI copy, alerts, logs, docstrings, README, and user notifications. Ensures compliance with Indian financial regulations.
---
- Never make performance promises, guaranteed win rates, or expected return claims.
- Never use unregistered investment advice language (e.g. "Sure shot multibagger", "Guaranteed profit").
- Clearly label paper-trading mode and delayed free data feeds.
- All numbers shown to the user must carry source and as-of timestamp.
